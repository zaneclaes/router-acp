# Finish accepted work

Finish only the accepted revision and only with the repository's required
authorization. Push or preserve the artifact and record a durable handoff with
planner_workflow finished. If finishing changes the reviewed revision, submit
the new artifact and return to parent review before integration.

Keep review and recovery evidence. Confirm custody before permitted cleanup.
Never delete the only artifact or a branch still required for integration.
Do not claim merge, deployment, or publication without its required proof.
