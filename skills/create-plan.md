# Create or refine the whole plan

Investigate the request and repository contracts. Present a concrete plan with
scope, files, dependencies, checks, risks, and completion evidence. Preserve
original requirements and decisions. Store the plan in the repository's
established Markdown layout. Honor a supplied destination.

Ask a structured question only for unresolved decisions or required scope
approval. Existing human authorization remains valid. Planning can resume after
implementation starts. A planning command does not cancel assigned children.
