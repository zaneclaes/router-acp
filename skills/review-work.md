# Review a bounded artifact

Adopted unfinished work requires parent `planner_workflow reconcile` before resumption:
complete current WorkSpec, carried source_revision and custody evidence. An obsolete worker
may use host-verified `retire` after its attempt ends and the parent takes over its remaining
obligations. Retirement never supplies integration proof or deletes source.

Independently inspect the assigned scope, artifact diff, declared checks, and
bounded evidence. Review every artifact. Do not skip review based on confidence
or rerun unrelated full release probes. Missing required proof stays pending.

Record acceptance or specific corrections through planner_workflow review,
bound to the exact artifact revision. Corrections return to the same child.
Changing the artifact invalidates prior acceptance. Keep any separate
repository review after completion separate from this work review.

Use status with work_id for a targeted delta. Integration requirements remain mandatory
later. Exact packet replays preserve review; changes invalidate it. After acceptance
and an ended attempt, finalize can record a complete handoff only when the host verifies
custody/resources. Otherwise resume finish-work. Prioritize release/disposition actions.
